Política de Privacidade

O Minecraft Server Backup é uma ferramenta pessoal para criar cópias de segurança de um servidor no Minecraft.

Dados acessados

O Rclone utiliza autorização OAuth para acessar o Google Drive escolhido pelo proprietário, a fim de criar, consultar, atualizar e excluir arquivos de backup.

Uso dos dados

Os arquivos são enviados diretamente do servidor do proprietário para sua conta Google Drive. Este site não coleta arquivos, tokens ou credenciais.

Armazenamento

O proprietário mantém os dois backups diários mais recentes na pasta MinecraftBackups do Google Drive.

Segurança

As credenciais OAuth ficam armazenadas localmente no servidor e não são publicadas neste site.

Contato

Entre em contato com o proprietário para eventuais dúvidas sobre esta ferramenta.
